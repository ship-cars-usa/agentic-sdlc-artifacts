# agentic-sdlc-artifacts

Generated artifacts from the agentic SDLC skills — kept here so they're shareable
and versioned, separate from the skills and the source repos.

## Layout

- **`CDR/`** — Change Design Records. One folder per change (`<JIRA-KEY>/` or `cdr-NNNN/`),
  each an editable `cdr.json` + a self-contained `index.html` + `diagram.svg`.
- **`jira-breakdowns/`** — story breakdown docs produced by the grooming skill. Empty for now.

Produced by the `breakdown-story` skill; do not hand-edit the generated files unless intentional.
