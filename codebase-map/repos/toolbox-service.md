# toolbox-service

## What it is
**Toolbox service** — README framing: "Contains various utility-like service that are too small to warrant a service on their own," i.e. the fleet's intended catch-all for small helpers. **In the current source the only utility actually implemented is a URL shortener / redirect service.**

The one endpoint set is under `/api/link`:
- `POST /api/link` — accepts a raw URL, validates it (`URI.create(url).toURL()`), persists a `LinkEntity` keyed by a base32 random UUID, and returns the public short URL (`public.link.url` + `/` + id) with `201 Created`.
- `GET /api/link/{id}` — looks up the link and issues a `307 temporaryRedirect` to the original URL (or `400` for an unknown id).

Templated from `quarkus-imperative-boilerplate`. Multi-module (8 poms). No REST clients, no Pub/Sub.

## Key abstractions
- `ShortenerController` — `resources/.../toolbox/rest/ShortenerController.java` — JAX-RS resource at `/api/link` (POST create, GET `{id}` redirect); maps `URISyntaxException`/`IllegalArgumentException` to `400` via `@ServerExceptionMapper`.
- `ShortenerService` — `services/.../toolbox/url/ShortenerService.java` — `createLink()` / `getLinkById()`; wraps writes in `TransactionalExecution`; ids from `SCUuidUtils.uuidToBase32Random()`.
- `LinkRepository` — `services/.../toolbox/url/LinkRepository.java` — Panache repository for `LinkEntity`.
- `LinkEntity` — `db-entities/.../toolbox/entities/LinkEntity.java` — `{id (base32 UUID PK), link (original URL)}`.

## Don't-do-here / gotchas
- **The name oversells the content.** Despite the "toolbox of many utilities" README, today it is a single URL-shortener. Don't assume other tools live here without checking `services/` — and if you add an unrelated helper, weigh whether it belongs in its own service.
- **`GET {id}` open-redirect surface** — the stored URL is redirected to verbatim; the only validation is at create time (`toURL()`). Anyone who can POST controls a redirect target under the public link domain. Restrict who can create links and/or validate the scheme/host on POST.
- **No expiry / GC on links** — `LinkEntity` rows are never TTL'd; the table grows unbounded.
